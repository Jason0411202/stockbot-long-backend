# 模擬帳本與回測一致性

本服務是模擬帳本，於台灣時間 09:10–09:30 以當日開盤價記帳；沒有券商委託或成交確認，也未計入手續費、稅與滑價。策略門檻、冷卻天數、先買後賣順序維持既有設定。

## 每日提交與恢復

每個交易日使用獨立的引擎副本，在同一筆 MariaDB transaction 中寫入所有買賣、現金、累計注資、風控狀態及 `last_processed_date`。`BotState.trading_lock` 序列化帳本寫入；提交失敗不發布引擎副本或成交通知。包含 COMMIT 回應遺失在內的失敗，下一次嘗試必須重新讀取持久化狀態。

`risk_<stock_id>` 保存最後買入日、最後移動停利日與持倉峰值，避免開盤後重啟時因日 K 棒尚未到齊而失去峰值。舊帳本首次升级仍由既有交易紀錄重建，持倉買入價也納入峰值。

每次開盤決策前先驗證全數標的已有前一交易日資料，再依序補跑未處理的交易日。部分標的缺 K 棒、缺開盤價、更新失敗，均不允許越過缺漏日推進水位線。09:29 不再以不完整行情強制成交。跨月停機的回補範圍會延伸至最後處理月份。

當月尚未公布第一筆收盤（也可能涵蓋分割停牌），TWSE 明確的「沒有符合條件的資料」回應視為尚待公布，不視為連線失敗、不寫入假 K 棒或完成標記。前一交易日資料完整性仍逐檔驗證；歷史月份缺資料、HTTP／解析失敗仍回傳錯誤，不能用這個例外放行過舊行情。

休市與前一交易日由 TWSE `holidaySchedule` 的 `date=YYYY0101` 查詢取得；週末直接排除，行事曆無法確認時暫停決策。分割倍率及停牌期間由證交所公告自動取得與保存，無需人工確認。行情來源失敗仍自動重試，不把錯誤報價當成分割。

## 估值與績效

15:00 後每 15 分鐘更新完整日行情，補上收盤權益；下一次開盤前也會補做前日收盤估值。開盤估值只用於監控，不作為已完成的收盤歷史。

歷史 API 從完整的已實現片段與未實現餘額還原逐日持股，以當日收盤重新估值，保留原有現金與交易；原始 `EquityHistory` 舊列保留供稽核。收盤未齊的日期不顯示為已結算歷史。最新持倉 API 提供 `price_date`、`price_basis`，今日新買部位在收盤入庫前以開盤成交價暫估，避免拿昨日收盤算買入後報酬。`max_drawdown` 表示截至當日最差回撤；`strat_drawdown` 和 `bh_drawdown` 仍是當日距歷史高點的回撤。

既有帳本繼承過往策略版本，全期回測使用目前設定從期初重跑，兩者不必重合。比較交易一致性必須使用相同現金、持倉、最後買賣日、峰值及價格序列。

## 驗證與部署

`go test ./...`、`go vet ./...` 與 CI 的 `go test -race` 涵蓋交易日失敗回滾、第二標的寫入失敗、提交重試去重、行情缺漏、漏日回放、月末月份回補、開盤峰值重啟及估值回撤。

以 2026-09-30 稽核匯出的正式資料做隔離重播：使用官方 1:22 倍率後，全期回測至 9/29 為 872,968.09545455 元；由 9/8 原持倉接續至 9/30 的現金為 687,283.5769008235 元，與原交易結果一致。重新估值 1,804 個收盤快照（含分割停牌期間沿用最後有效估值）後，9/29 帳本權益為 1,144,043.83 元。

GitHub Actions 使用 commit SHA 固定映像及部署檔，保留 `releases/<sha>-<run>-<attempt>/previous/` 中的映像名稱、設定與完整資料库備份，不執行 prune 或清除資料。新服務就緒檢查失敗時恢復前一映像。`/health.version` 與績效摘要的 `strategy_version` 可核對實際版本。

## 自動分割與固定帳務單位

TWSE `TWTC9U` 公告提供倍率、停止及恢復買賣日期；`TWTCAU` 提供歷史恢復買賣參考價格。歷史倍率依官方參考價（含跳動單位捨入）還原，絕不以恢復交易後的實際開盤／收盤價推算倍率。公告每小時更新、整份存入 `BotState.market_units_v1`，成功持久化後才供讀取。重啟、重送、停機跨越分割都不會重複調整帳本。

帳務採固定的 `2026-09-30` 單位基準，此日期是帳務版本，不能隨最新行情移動。令 `C(d)` 為截至日期 d 的官方股數倍率乘積，`F(d)=C(d)/C(基準日)`，則：

- 所有行情輸入（DB OHLC、MIS 開盤、CSV、指標、B&H）都使用 `原始價格 × F(d)`；原始 DB 行情不改寫。
- 引擎、既有交易、整數買入取整、成本、持有峰值及冷卻日期都保留固定單位，企業行動不產生買賣或現金流。這是模擬帳本的等值單位，不是券商委託股數。
- 網站及通知顯示 `帳務價格 ÷ F(顯示日)`、`帳務股數 × F(顯示日)`；歷史曲線、買賣標記和持倉使用相同尺度。成本、收益、損益、權益金額不變。
- 反分割的等值零碎股數不截斷，避免資產消失。此模擬模型保留等值權益，不模擬券商的畸零股現金贖回。
- 官方停牌期間不要求該檔開盤或日 K，其他股票照常處理，持倉使用最後有效價格估值；恢復交易後自動接續。已完成舊公告若缺停牌起日，僅在官方事件前不超過 14 日的資料間隙推導，不能把長期缺資料當成停牌。

`cmd/fetch_data` 自動附存 `market-units.json`，CSV 回測讀取相同快照；DB 研究命令讀取正式持久化的單位設定。預設離線快照含本專案既有的 00631L 2026-03-31 1:22 事件。新增標的或更新 CSV 必須使用一併更新的官方事件快照。

舊版用 443.15 → 19.26 的實際收盤比值得到約 1:23.0088，誤把恢復交易當天約 -4.38% 報酬消掉。正確前收應為 443.15/22，故新回測數字必然變更；隔離重播確認首次超過 1% 的權益差異發生於 2026-03-31。修正行情不重寫既有模擬成交，9/8 原持倉接續的交易結果及目前資產不變。

新增測試覆蓋二倍分割、22 倍分割、反分割與零碎權益、連續事件、保留實際報酬、OHLCV 一致換算、即時／回測一致、停牌後自動恢復、重啟去重、公告持久化失敗、API 價量與金額恆等式。
